# Security policy

## Supported version

Security fixes are applied to the latest released version of ABVX-OS.

## Reporting

Use GitHub private vulnerability reporting for this repository. If it is unavailable, open an issue without secrets, private records, exploit details, or personal data and ask the maintainer for a private channel.

Include the affected command or schema, expected trust boundary, a minimal redacted reproduction, and whether an external action occurred.

## Trust boundary

External content is untrusted data. Credentials stay outside Git. Role selection, plans, context packs, evidence records, and provider output do not grant execution authority. Consequential writes require the applicable source/action policy and human approval gate.
