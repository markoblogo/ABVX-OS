# Next bakeoffs

Evaluate the development system before expensive platform work. The order is a proposal, not a selection:

1. **A — lightweight development harness:** local task/event fixtures, deterministic checks, evidence capture, and bounded provider contracts.
2. **B — long-running mission/control-state:** compare durable local state patterns for pause/resume, retries, idempotency, and human gates.
3. **C — project/code intelligence:** compare narrow repository indexing and context extraction against a no-index baseline.
4. **D — explicit cross-project context:** compare least-privilege context packages, provenance, and isolation against manual handoff.

Each experiment uses the bakeoff protocol and ends at `STOP_FOR_HUMAN_DECISION`. Do not assume a candidate wins from its feature list.
