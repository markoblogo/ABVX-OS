# ABVX-OS v0.1.0

The first public release establishes ABVX-OS as an inspectable local-first Personal Operator reference implementation.

## Highlights

- 187 repository tests and a schema/registry/evidence validation gate.
- Deterministic professional-role routing without tool or authority escalation.
- Universal Intake, portfolio state, bounded context retrieval, playbooks, bakeoffs, Book Radar, and publishing gates.
- CI, agent-context drift checks, explicit ecosystem boundaries, and separate code/content rights.

## Try it

```sh
git clone --branch v0.1.0 https://github.com/markoblogo/ABVX-OS.git
cd ABVX-OS
./bin/abvx validate
./bin/abvx role route --text "Research a market and prepare a book brief" --json
```

The release is a source checkout. It is not a hosted service or autonomous executor.
