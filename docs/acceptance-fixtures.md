# Acceptance fixtures

Foundation must later support these real input classes without implementing integrations in FOUNDATION-001:

- URL relevant to an existing project’s media/research layer
- Screenshot relevant to a project/reference
- Screenshot suggesting a revenue hypothesis
- GitHub repository candidate
- Startup-grant dataset
- LinkedIn inbound commercial/job opportunity
- Project support/bug channel message
- Human spontaneous idea
- System-generated content hypothesis

Fixtures must be redacted, attributable, versioned, and safe to replay. No real fixture is included until its source, permissions, and retention policy are known.
