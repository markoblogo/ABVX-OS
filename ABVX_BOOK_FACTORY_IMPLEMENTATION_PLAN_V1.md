Architecture approval gate only. No phase is executed by this package. Recommended foundation: hybrid universal core, reusing existing GD3 mechanics; first consumer GD3. ## Ranked first slice

Phase 1 only: identity/state/event/evidence/validator/conditional-lock contract, thin read-only generic status/validate facade, synthetic two-type tests. Extract/test existing GD3 helpers; keep `book status gd3`/`book validate gd3` behaviour and initial state. No new builder, external runtime, dashboard, database, source migration or creative task. Adapter extraction changes are a separate approved implementation run.

Priority rationale: hash-bound identity and readiness prevent recurrent wrong-source/gate errors across every case; Contents and complete geometry move owner-detected failures earlier; prospective instrumentation fixes unmeasurable cost/attention without inventing retrospective metrics. Reuse `book_preflight`, publishing gates and narrative runner, not a second framework.

## Regression queue

Blocking first: current-state/ledger mismatch; bytes changed under lock; missing/changed evidence; no-proof PASS; inherited metadata surface mismatch; STALE build/cover metadata. Then: RN2/Jekyll missing visible Contents despite bookmarks; stale Contents numbers/destinations; GD2 six margin pages and RN3 vectors/footer; font embedding/annotations; independent EPUB/DOCX vs retailer conversion; product-quality FAIL not overwritten by technical PASS; commercial version mismatch; expired retailer constraint not auto-cleared.

Translation/visual: persistent/unknown429 stops outer loop, bounded retry reserve, never double-count reasoning tokens; cache-policy/context mismatch; missing/duplicate/source-hash/order drift; TP claim-vs-fact/name/layer/glyph continuation; Jeanne lacuna preservation and source-witness hierarchy; Pictiq species/speaker/span/composer proof and scoped exception. Include adversarial malformed/NaN/rotation/coordinate inputs; no secret/error-body storage.

## Human and migration boundaries

Retain owner concept/story/translation ambiguity/native judgement, editorial acceptance/Text Lock, visual/Composer meaning, rights/AI/price/cover and final release. Automate only the eight mechanical tasks enumerated in architecture, inside current authority. No new approval for unchanged inherited defaults, but deviations still require one.

Migration: (1) new books first; (2) thin read-only adapters for active books only if explicitly approved; (3) optional historical linking only when it answers a real current question. Never normalize/copy old manuscripts, rewrite event history or backfill metrics from chat/file dates. Independent Jeanne/Odyssey/Bracken projects stay independent; use hashed external references, not absorbed ownership.

Before significant implementation, recheck capabilities/donor matrix. Existing local components beat importing LoopX/Dify/n8n. If a real future gap needs a donor, run a separately scoped bakeoff; this audit does not admit a provider. Schemas are additive/versioned and runtime coverage must include patterns, arrays and conditional rules, which the current custom schema validator does not fully implement.
